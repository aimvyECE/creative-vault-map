# Contributing

Open an issue describing a reproducible problem or a focused pull request with a test. This is an early solo prototype; there is no claim of an established contributor community.

Use only synthetic Markdown fixtures. Do not upload personal vaults, generated reports, credentials, copyrighted poems or other private content. Describe the supported syntax and behavior changes. Run `python -m unittest discover -s tests -v` before submitting.

The main design constraints are local-only operation, read-only source handling and explicit uncertainty rather than guessing ambiguous destinations.
